## How to Change Admin Credentials

1. Open file: `client/src/config/adminCredentials.js`
2. Update the values:

```javascript
const adminCredentials = {
  userId: 'your_new_userid',
  password: 'your_new_password'
};
```

3. Save the file
4. Refresh your browser

## Security Notes

**IMPORTANT:** This is a basic authentication system using localStorage. For production use, consider:

1. **More Secure Authentication:**
   - Use Firebase Authentication instead
   - Implement proper session management
   - Use JWT tokens

2. **Password Security:**
   - Never commit credentials to Git
   - Use environment variables
   - Hash passwords on the backend

3. **Current Implementation:**
   - Credentials stored in code (not recommended for production)
   - Session stored in localStorage
   - No password encryption
