## How to View Orders in Firebase Console

### Step 1: Go to Firebase Console
1. Visit: https://console.firebase.google.com/
2. Select your project: `print3d-1e16c`

### Step 2: Navigate to Firestore
1. Click "Build" in left sidebar
2. Click "Firestore Database"
3. You'll see your database collections

### Step 3: View Orders
1. Click on "orders" collection
2. You'll see all order documents listed
3. Click on any order to see full details

## Understanding Order Fields

### Customer Details
- **name**: Customer's full name (from Google)
- **email**: Customer's email address
- **mobile**: Customer's phone number
- **address**: Delivery address
- **userId**: Unique user identifier

### Order Items
Each item includes:
- **name**: Product name
- **category**: Product category
- **price**: Unit price
- **quantity**: Number of items
- **subtotal**: price × quantity
- **image**: Product image URL

### Pricing
- **subtotal**: Total before discount
- **discount**: If coupon applied
  - code: Coupon code used
  - percentage: Discount %
  - amount: Discount amount in ₹
- **total**: Final amount to collect

### Order Metadata
- **orderNumber**: Unique order ID (ORD-timestamp)
- **status**: Order status (default: "pending")
- **createdAt**: Order timestamp (ISO format)

## Filtering Orders

### By Date
1. In Firestore, click "Filter"
2. Select field: `createdAt`
3. Choose operator and date

### By Status
1. Click "Filter"
2. Field: `status`
3. Value: "pending" or other status

### By Customer
1. Click "Filter"
2. Field: `customer.email`
3. Enter customer email

## Exporting Order Data

### Method 1: Manual Copy
1. Click on an order
2. Copy the JSON data
3. Paste into a text file

### Method 2: Firebase Admin SDK (Advanced)
- You can write a script to export all orders
- Requires Firebase Admin SDK setup
- Can export to CSV or Excel

## Setting Up Email Notifications (Optional)

You can set up Firebase Cloud Functions to:
- Send you an email when new order arrives
- Send confirmation email to customer
- This requires Firebase Blaze plan (pay-as-you-go)

## Order Fulfillment Workflow

1. **Customer places order** → Saved to Firestore
2. **You check Firebase Console** → See order details
3. **Contact customer** → Using mobile/email from order
4. **Update order status** → Change "pending" to "processing"
5. **Ship product** → Update to "shipped"
6. **Delivery confirmed** → Update to "completed"
